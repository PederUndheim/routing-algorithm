# Save Learning

Read `WORKING.md`, existing `CONTEXT.md`, and relevant decision records. Save the minimum information that will make a future session meaningfully cheaper or safer.

Classify each candidate:
- Stable vocabulary, invariant, convention, or architecture anchor: update `CONTEXT.md`.
- Costly-to-reverse decision with real alternatives: create or update `docs/decisions/YYYY-MM-DD-short-title.md`.
- Current progress or next action: update `WORKING.md`.
- Cheaply rediscovered, speculative, duplicated, or temporary: do not save.

Keep wording compact and prefer links to paths and symbols over copied explanations. Report what was written and what was intentionally discarded.
